# Prototype Response Guidance

This project-owned checklist is a demonstration source for the response-support pipeline. It is not an official military maintenance manual.

- Fix the video and detection time, then re-detect the same location.
- For repeated detections, report the location and result to the control operator and check adjacent sensor status.
- When repetition is confirmed, have maintenance personnel inspect external condition and fastening status.
- Record the detection and action result in the operations log.
